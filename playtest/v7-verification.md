# Penguin Jump v7 検証記録

検証日: 2026-10-01。ユーザー指摘の「右へ歩くしろくまの表示崩れ」を v6 の実 ROM で再現し、ネイティブスプライトの配置を修正した。

## 原因と修正

24 px 幅のキャンバスでタイル X 座標を 0 / 8 / 16 にしていたが、GB Studio 4.3.2 のコンパイラーは 16 px を基準とする中央原点（この素材では +4 px）を加えて判定する。このため右端 4 px がキャンバス外となっていた。コンパイラーの `removeIndexedImageMask` は範囲外を Unknown とし、タイル共有処理がその部分を別タイルの画素で埋めた結果、頭などの表示が崩れた。

タイル X 座標を -4 / 4 / 12、`canvasOriginX` を -4 に補正。元 PNG は変更せず、描画位置と当たり判定を保持した。素材生成スクリプトにも同じ補正を適用した。ゲームプレイの C ソース、パレット、共有コンパイラーは変更していない。

前回は歩行画像を確認しながら、右向きの崩れを見落としていた。OAM の個数が上限以内でも絵の正しさは保証されない。今回、ROM に収録されたタイル・属性・座標から全コマの画素を復元して元画像と照合する検査を追加した。
