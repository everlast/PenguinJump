## 実 ROM のプレイ確認

PyBoy 2.7.0 / CGB モード。公開 `emulator_step` に通常のボタン入力を送り、実際の 160×144 フレームを確認しました。途中からは位置を読み取ってジャンプのタイミングを決める入力回帰シーケンスを併用。WRAM / OAM は読み取りだけで、位置・得点・無敵時間の書き換えは一切行っていません。

| 確認 | 結果・フレーム |
|---|---|
| 低い氷・高い氷、魚の回収 | 両方をジャンプで回避。最初のコースは全 72 匹を回収 |
| コースを自動で継続 | 1 コース目の結果 f1353 → 別配置の次コース f1423 |
| 99 → 100 匹の境界 | f1821: 魚 99・無敵 0。f1843: 魚 100・無敵残り 474 更新 |
| 一時停止 | f1857 → f1977 の 120 フレームで位置、魚、無敵残り 474 が不変 |
| 無敵中の衝突 | ジャンプせず地上を走り、複数の氷を通過して生存。f2199: 魚 110 |
| 無敵終了 | その後に通常衝突で GAME OVER。f2529: 1 コース・魚 120・無敵 0 |
| 再挑戦 | f2581: クリア数・魚・無敵が 0、別配置。ベスト 1 コース・120 匹は維持 |
| 200 匹でも再発動 | f5911: 魚 204・無敵残り 418。100 匹のときから再発動 |
| コース間の持ち越し | f6170: 3 コース・216 匹・無敵 184。次コース f6241 は 216 匹・無敵 175（再開後の走行分だけ減少） |
| 連続 5 コース | f8449: 5 コース・魚 360。速度上限 2 px/更新のコースも完走 |
| 記録の確定 | 6 コース目で意図的に無入力。f8862: GAME OVER、BEST 5 コース・363 匹 |
| ブラウザー版 | 最終版のタイトルから画面 A ボタンで開始し、魚の回収と GAME OVER を実表示で確認 |

生成は 16-bit PRNG を使用し、開始・再挑戦の入力タイミングを種に混ぜます。観測した各コース・再挑戦では氷の配列が異なりました。すべての可能な種を網羅した試験ではなく、数学的に配置の再出現を禁止するものでもありません。

無敵は走行中のゲーム更新 480 回を基準とする約 8 秒。停止・コース結果中は減りません。人の操作による難易度の評価や、実機の処理時間測定は未実施です。
