# Penguin Jump v19 検証記録

検証日: 2026-10-03 (JST)。実機は未書き込み、最後に書き込み成功を確認した版はV18です。

## 実装

- ステージ20以降（内部level>=19）に、吹雪・氷柱3倍・隕石3倍を各10%で独立抽選。同時発生に対応。HARDの初回も対象。
- 抽選は通常の配置生成後。穴4個、熊2体、通常抽選後の氷・浮遊ブロック、魚60匹を保持。氷柱は区間数×3本、隕石は3個。
- 3個は8物理ティック間隔で出現。物理時間はスクロール速度と連動。魚の位置・予兆なし・接触死・無敵の防御を維持。
- 吹雪は全体の配色を薄くし、空の共有タイルで雪をアニメーション。HUDパレット7は変更せず、追加のハードウェアスプライトを使わない。
- 氷柱3倍には8 px幅の専用フレームを追加。既存の通常2フレームと登録IDは保持。既存21アクター内で描画し、隕石で一時使用した雪玉枠を復元。

## 実ROMの通常操作

公開PyBoyツールで通常ボタンのみを入力。RAM・ステージ・抽選結果の強制変更は行っていません。自然に抽選された各モードと併発の状態を保存し、同じROMへチェックポイント復元して分岐検証しました。

| 検証 | 結果 |

| 3モード同時発生 | weather=7で1コースクリア、氷柱3本・隕石3個・魚53匹。穴4個と両方の熊を通過 |
| 氷柱3倍 | 序盤・中盤・終盤の3区間、合計9本が実際に出現。二段ジャンプでコースクリア |

| 吹雪の停止・解除 | 一時停止40フレームで位置・ゲーム時間・雪タイルのバイト列が不変。通常へ再抽選された再挑戦で背景パレット復元、HUDパレット不変 |
| モード切り替え | 吹雪のゲームオーバー→B→NORMALで再開。通常の色・魚0・速度56・weather=0に復帰し、1コースクリア |

## 実ソースのホスト検査

`python3 playtest/check_v19_weather.py` が、実際のCソースから抽選・コース生成・落下関数を抽出して検査します。これはエミュレーター実行とは別の証拠です。

- 全65,535シードで8通りの組み合わせが発生。吹雪10.001%、氷柱9.999%、隕石9.999%。
- 1,000シードでNORMALの20ステージ目とHARD初回の配置・抽選が一致。最大速度84で各コースの氷柱が区間数×倍率、隕石が倍率どおりに出現。隕石は熊の攻撃開始距離へ入る前に終了。
- NORMALの1〜19ステージ×50シード（950件）で特殊モードなし。

## 発見した不具合と制限

初回実装の氷柱3倍は、同時接地中に最大12個/走査線となりました。元の失敗録画と `v19-initial-oam-failure.json` を残し、増量時専用の細い氷柱を追加して再ビルド・再検証しました。最終ROMでは上記の超過なしを確認しています。

ホスト検査の最初のリンクはmacOS SDKの不整合で失敗しました。選択中のXcode SDKをxcrunで明示して実行し直し、検査を完了しました。

ブラウザーは旧V16のclosureState unresolvedと終了応答UNKNOWNが続いています。未解決処理を再送せず保存状態を保持し、V19のWeb出力・表示確認は未実施です。実機のV19での起動・操作・音、NORMALで1から20ステージまでの通しプレイ、全シード・全フレームの描画は未確認です。
