# 検証記録の公開範囲

V1〜V19の検証レポート、実ROMの画面、観測JSON、入力補助、実機書き込み結果を収録しています。JSONと文書の個人用絶対パス・ローカルプレビューURL・接続トークンは公開用に置換しています。未加工の記録は制作環境に保持しています。

ビルド時点の検証記録はその時点の状態です。V19は検証後に実機へ書き込み済みで、後続の記録は `flash-v19.md` / `flash-v19-result.json` を参照してください。書き込み正常終了と実機の起動・音・操作確認は別です。

録画フレーム一式、エミュレーターのセーブ状態、古いブラウザープレビュー、コンパイラー本体は含めません。これらのパスを含む観測JSONは履歴資料であり、このリポジトリだけで復元できるセーブデータではありません。`*-playtest-runner.js` はModRetro Chromaticツール環境用の補助コードで、単独のNode.jsスクリプトではありません。

最新のホスト検査はmacOSのXcode Command Line ToolsとPython 3で実行できます。

```sh
python3 playtest/check_v19_weather.py
```
