# Penguin Jump 検証記録

実施日: 2026-10-01（日本時間）

## ビルドと対象

- GB Studio CLI 4.3.2 / GBDK 4.5.0 / エンジン `4.3.0-e1`。
- ネイティブの `project.gbsproj` から公式 `make:rom` でビルド。終了コード 0。コンパイルエラーなし。
- ROM: `build/PenguinJump.gbc`、131,072 bytes、GBC 専用（CGB フラグ `0xC0`）、MBC5。ヘッダーチェックサム・Nintendo logo の検査は正常。
- ROM SHA-256: `c8791dfe5d5cbb9b971948b47a246e5d24003faa86e97a399c19aa8220811c24`
- CLI の既知の Node `DEP0190` 警告は残っています。ビルドは成功しています。
- 公式 `make:web` の別ビルドを Codex 内蔵ブラウザーで確認。Web ROM SHA-256: `f6fec82f8dd4b5cd2e3dd10f92922a2de037ac5dbbc87a521258dfa595a24780`。

## 実 ROM の操作確認

PyBoy 2.7.0 の GBC モードを使用。プラグインの `emulator_step` で入力し、160×144 の実フレームバッファーを各ジャンプ後に確認しました。ゲーム状態を書き換えるチートや位置の直接移動は使用していません。

| 確認 | 結果・証拠 |
|---|---|
| タイトル → ゲーム開始 | A 入力でコースへ移動 |
| 自動走行・横スクロール | 前方を広く表示しながら右へ移動 |
| 短いジャンプ | フレーム 244 の A 1 フレーム入力後、離して最初の 16 px の氷を回避 |
| 長押しジャンプ | 32 フレームの A 入力で 24 px の氷を回避 |
| 全コース完走 | 12 個すべてを回避し、フレーム 1370 に `COURSE CLEAR! / 12/12 CLEARED!` を確認 |
| クリア後 | A でタイトルへ戻ることをフレーム 1451 で確認 |
| 一時停止 | START で停止。フレーム 1603 と 1663 の表示・プレイヤー OAM 座標が同一 |
| 再開 | A で走行を再開 |
| 衝突・失敗 | 無入力で最初の氷に当たり、フレーム 1864 に失敗画面を確認 |
| 再挑戦 | A 入力後、フレーム 1950 にコース開始位置から走行していることを確認 |
| ブラウザー版 | タイトル、画面 A ボタンで開始、最初の氷で失敗表示を確認。検証用プレイを Restart game で終了し、タイトルで待機 |

最終ビルドの全入力とフレーム画像は `build/playtest-v1/`、軽量の入力記録は `input-events.json` に保持しています。`gameplay.gif` は実フレームの 3 区間（210–290 / 385–444 / 1160–1310）をつないだ約 4.9 秒の無音抜粋で、全区間の連続動画ではありません。

## 制作中に修正した点

- カメラがペンギンを右寄りに置いていたため、前方を見渡せる左寄りの位置へ変更。
- 標準フォントで画面幅を超えていた失敗・クリア・停止の文を 16 文字以内へ変更。
- タイトル背景の局所パレットによる不要な橙色の領域を修正。
- 短押し時の速度制限で低い氷を越えにくかったため、その制限を除去。短押しでも低い氷を回避し、長押しではさらに高く跳べることを確認。

初期の失敗記録は `build/playtest/`、`build/playtest-final/`、`build/playtest-release/` に残しています。これらは古いビルドの証拠で、最終版の確認には使用していません。

## グラフィックと未確認項目

コース背景は 98 種の固有 8×8 タイル、背景パレット 2 個を使用。解析時の上限 384 タイル以内です。ペンギンは 2 個の 8×16 ハードウェアスプライトで描画します。制作中の OAM 観測では走行時の同一走査線上は最大 2 個でした。全場面の最大値を測定したものではありません。

Chromatic 実機での起動、表示、操作、音、消費電力、入力遅延は未確認です。効果音の聴感評価や PCM 検証も行っていません。ROM ヘッダーに RAM/BATTERY が指定されていますが、ゲームには永続セーブ機能を実装していません。
