## 確認結果

| 項目 | 実測 |
|---|---|
| ランダム配置 | 再挑戦で位置と穴の場所が変化。各コースで氷 8 個・穴 4 個を確認 |
| 歩いて穴へ入る | frame 438 で落下開始。A を押しても落下継続し、GAME OVER |
| 短いジャンプで穴の途中に着地 | 6 コース目の幅 40 px の穴で落下し、GAME OVER |
| 幅 32 px の回避 | 初期速度からジャンプで通過。落下しない |
| 幅 40 px の回避 | 3 コース目から出現。無敵なしで回避し、5 コース目の最高速度でも通過 |
| 連続クリア | 5 コースをクリア、魚 356 匹。6 コース目で意図的に落下し、結果・ベストは 5 コース / 368 匹 |
| 魚 100 匹ごとの無敵 | 100・200・300 匹を通過し再発動。残り時間の減少、終了、コース持ち越しを確認 |
| 無敵中の穴 | frame 2443: 穴 x=944〜975 内に足がある状態で y=112・落下なし・無敵 370。地上のまま渡り切れた |
| 一時停止 | frame 2242→2362 の 120 フレームで無敵 446、魚 102、位置、ゲーム進行時間が不変 |
| 再挑戦 | 今回のコース・魚・無敵をリセット。ベストを保持し、別配置で再開 |
| HUD と穴 | 穴の絵は y=120〜127。落下中のペンギンは HUD に届く前に非表示。スコアの重なりを修正後、実描画で確認 |
| OAM | 119 サンプルで同一走査線の最大 7 / 上限 10。観測したサンプルに超過なし |

穴の上の魚はジャンプで取れる。無敵の地上通過を試すため、一部の空中の魚は意図的に取り逃している。短押しと長押しでジャンプの高さ・滞空時間が変わるため、穴には長押しが有効。
