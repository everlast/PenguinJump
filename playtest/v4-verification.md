## 動作確認

| 項目 | 結果 |
|---|---|
| 一段目 | A 長押し中はジャンプ消費 1 回のまま |
| 二段目 | 空中で A を離して押し直すと再上昇、消費 2 回 |
| 三段目の禁止 | 追加の A 入力で速度が再上昇せず、消費 2 回のまま |
| 着地 | 残り回数が 2 に戻り、A を保持しても自動では跳ばない |
| 高い氷 | 48 px は最初のコースから、56 px は 3 コース目から二段ジャンプで通過。最高速度でも成功 |
| 高い氷に一段のみ | 48 px の氷に衝突し GAME OVER。二段が必要であることを確認 |
| 広い穴 | 56 / 64 px の穴を二段ジャンプで通過。最高速度、広い穴が隣り合う配置も成功 |
| 広い穴に一段のみ | テストした踏切位置からは途中へ着地して落下。追加の A でも復帰せず、HUD は J:0 |
| 連続走行 | 5 コース、50 障害物を通過。クリア時に魚 294 匹 |
| 無敵 | 累計 100・200・300 匹で発動。6 コース目で幅 64 px の穴と高さ 48 px の氷を地上通過。終了後は通常の衝突でミス |
| 空中での一時停止 | 120 フレーム停止し、位置・速度・ジャンプ消費数・無敵残り時間が不変。再開後の挙動も正常 |
| 結果と再挑戦 | 6 コース目でミス、結果・ベスト 5 コース / 魚 318 匹。再挑戦時に今回の数値をリセットし、別配置、ベスト保持を確認 |
| ハードウェア表示制限 | OAM の 69 サンプルで同一走査線最大 9 / 上限 10。サンプル中の超過なし |

1 コースは氷 6 個・穴 4 個・魚 60 匹。障害物間隔は 160〜192 px。二段ジャンプ後に着地する余裕を確保した。魚は障害物に応じて高い軌道へ配置し、最初のコースでは 60 匹すべて回収できた。

## 実描画と修正

高い氷・広い穴・HUD・二段ジャンプの上下動を実フレームで確認。高い氷は積み重なった見た目で通常の氷と区別でき、HUD の J は残りジャンプ数を示す。

初回テストでは画面外の穴スプライトも OAM を消費し、隣り合う穴で上限を超過した。左右の見えないタイルを省くネイティブフレームを追加し、最終 ROM で最初から再試験して解消を確認した。初回の自動入力には A を離さずに次のジャンプを試みた失敗もあり、入力手順を修正して再検証した。失敗時 ROM・状態は `v4-initial/` と `v4-initial-evidence.json`、過去の入力・フレームは `../artifacts/recording-archives/` に保持。
