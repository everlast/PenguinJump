- `generate_course` の魚配置で、氷柱・隕石を既存の地上列と同じY=112に統一しました。各6匹・横位置は維持しています。

## 実ROMでの確認

公開PyBoyを通常のボタン入力だけで操作しました。RAMやステージの強制変更は行っていません。`build/playtest-v18-release` に2,602フレーム・1分岐を保持し、passedで終了しました。

| 確認項目 | 実測 |
|---|---|
| 氷柱の魚 | 序盤slot0・中盤slot5・終盤slot9の全6匹がY=112 |
| 隕石の魚 | 最初の障害物ペアのslot1 / slot2のどちらでも全6匹がY=112 |
| 表示 | 隕石・氷柱の実画像と、魚tile28のOAM描画Y=104（スプライト上端）を確認 |
| 地上での回収 | プレイヤーY=112のまま接近し、各観測区間で2〜3匹を回収。中盤の氷柱手前は3匹を回収 |
| 回避・進行 | HARDを2コース連続クリア、累計魚110。氷柱・隕石は通常のジャンプで回避 |
| メニュー再開 | 無敵終了後にゲームオーバー、B→左→STARTでNORMALに戻り、魚0・初速56・21アクターを確認 |
| 他のジャンプ魚 | NORMAL再開時に広い穴の後半3匹は84 / 64 / 40、高い氷は72 / 40 / 56で維持 |
| スプライト上限 | 2コース目を最大4フレーム単位に区切った観測を含む438 OAM標本で最大9個/走査線、10個制限超過0件 |

再開検証の最初の固定待機では、魚100匹による無敵が7フレーム残っていたため、ゲームオーバーを期待する検証条件が一度失敗しました。状態を確認し、無敵終了後のゲームオーバーまで待って検証を継続しました。ゲーム側の修正は不要でした。

NORMALを10 / 20ステージまで進める通し検証、実機のV18での表示・操作は未確認です。魚生成は両モード共通の処理を確認しました。
