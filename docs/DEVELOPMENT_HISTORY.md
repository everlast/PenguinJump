# Penguin Jump — v19

ペンギンが星空の氷原を走る、Game Boy Color 専用の横スクロール・ジャンプゲーム。ミスするまで何コース続けてクリアできるか、魚を何匹集められるかに挑戦します。

## v19 の特殊モード

**ステージ20以降、コース開始時に次の3種類をそれぞれ独立して10%で抽選**します。同時発生もあり、次のコース・再挑戦では引き直します。HARDは開始時から20ステージ相当なので、最初のコースから抽選対象です。

- **吹雪**: 背景と登場物が白いかすみで見えにくくなり、空に雪が流れます。画面下のゲージ・文字は通常の配色を保ちます。一時停止中は雪も止まります。
- **氷柱3倍**: 通常の1〜3区間でそれぞれ3本、計3〜9本が降ります。左右に16 pxずつずらし、8物理ティック間隔で落下。増量時は描画上限に収まる細い氷柱を使い、高さ・接触死・地上滞在時間は維持します。
- **隕石3倍**: 通常の隕石区間で3個が降ります。8物理ティック間隔・右へ16 pxずつずらした同じ斜め軌道です。熊の攻撃区間へ入る前に終了します。

通常のコース配置を作った後に増量するので、**穴4個・熊2体や、通常抽選で残った氷・浮遊ブロックを減らしません**。魚は60匹のまま、氷柱・隕石の区間は低い魚の列を保ちます。落下の予告表示は追加していません。

画面下の `S` は吹雪、`I` は氷柱3倍、`M` は隕石3倍。併発時は同時に点灯し、左の `N` / `H` がゲームモードです。一時停止・結果画面では `SNOW / ICE / METEOR` で表示します。増量区間は二段ジャンプで越えられます。

3モード同時発生コース、氷柱9本のコース、NORMALの通常コースを実ROMでクリア。詳細は `playtest/v19-verification.md` を参照。

## v16 のゲームモード

オープニングの **GAME MODE** で左右キーを押し、**NORMAL / HARD** を選べます。SELECTでも切り替わり、白い項目が選択中です。A / STARTで開始します。タイトル右上は現在のバージョン、ペンギンのアニメーションは継続します。

| モード | 最初の難易度 | 初速 / BGM | 初回の攻撃 |
|---|---|---|---|
| NORMAL | 従来の1ステージ目 | 56/32 px/更新、120 BPM | 従来どおり段階的に解禁 |
| HARD | 従来の20ステージ目相当 | 75/32 px/更新、約160.7 BPM | 雪玉・氷柱・黒熊のハンマー・隕石が最初から登場 |

**両モードともクリア数0・魚0・無敵なしから開始**します。HARDの難易度だけに19コース分を加え、実際のクリア数には加算しません。クリアするたびに速度とBGMが上がり、上限は共通です。HARDでは9回クリア後に上限84/32 px/更新・180 BPMへ到達します。

ゲームオーバー後のA再挑戦は同じモードで、Bでメニューへ戻っても選択を保持します。NORMALへ切り替えて始めると通常の初速・攻撃解禁に戻ります。ベスト記録はモードごとに分離し、同じ起動中だけ保持します。プレイ中と結果画面にもモード名を表示します。

公式ROMの通常ボタン操作で両モードを各1コースクリアし、HARDの4種類の攻撃、加速、再挑戦、メニュー復帰、記録の分離、21アクターの再表示を確認しました。内蔵ブラウザーも更新済みです。詳細は `playtest/v16-verification.md` を参照。

**v16は実機未書き込みです。** 以下の過去版のステージ数・解禁条件はNORMAL基準です。HARDは20ステージ目相当から進みます。

## v15 の追加機能

- **動くオープニング**: ペンギンが足を動かしながら跳ねます。タイトル・操作案内は固定し、右上に現在のバージョンを表示します。A / STARTですぐに開始できます。Bでメニューへ戻ったときもアニメーションが再開します。
- **魚ゲージ**: プレイ中の魚の数字を80 pxのゲージへ変更しました。次の100匹に向けて左から蓄積し、100匹で満タンの無敵ゲージに切り替わります。無敵中は同じ場所のゲージが減り、終了すると次の100匹分の魚ゲージへ戻ります。魚の合計は一時停止・クリア・ゲームオーバー画面で確認できます。
- **20ステージ目から隕石**: 1コースに1回、地面の「!」を予告に、右前方の上空から炎を引いて左下へ落ちます。通常時は本体に触れると死亡し、無敵中なら消して通れます。炎の尾は当たり判定に含めません。

隕石は最初の障害物ペアの安全な地面にある高い氷を置き換え、同じ場所に穴・氷柱・熊・浮遊ブロックを重ねません。隣の配置とは160〜192 px離れ、攻撃はその区間内で終了します。落下と予告は速度に連動し、一時停止中は止まり、次のコースと再挑戦時にリセットされます。

公式CLIのROMを公開PyBoyで通常操作し、25ステージ目まで到達。隕石による死亡・ジャンプ回避・無敵時の消去と、メニューからの再開を確認しました。内蔵ブラウザーも更新済みです。詳細は `playtest/v15-verification.md` を参照。

**v15は実機未書き込みです。現在の実機はv13です。** タイトルの版は `art-source/create_art.py` の `GAME_VERSION` で管理します。

## v12 のランダム氷柱と黒熊

**10ステージ目から、1ステージにつき1〜3か所で氷柱が落下します。** 序盤・中盤・終盤の3候補から出現数と場所を毎回抽選し、同じ場所は重複しません。序盤に出ないコースもあります。地面の「!」で落下地点を予告し、落下した氷柱は短時間地面に残ります。通常時は触れると死亡、無敵中は砕いて通れます。

**15ステージ目から、2体の熊のうちランダムな1体が黒熊になります。** 黒熊はその場でハンマーを構え、放物線を描く回転ハンマーを1回投げます。通常時はハンマーに触れると死亡。ハンマーをジャンプで避け、黒熊を上から踏んで倒せます。横からの接触は死亡、無敵中はハンマーも黒熊も防げます。もう1体は従来のしろくまです。

新しい攻撃は既存の障害物区間を置き換えます。氷柱が選ばれた区間の通常氷・浮遊ブロックは配置せず、黒熊は同じ区間で雪玉を投げません。穴や隣の障害物とは160〜192 pxの配置間隔を保ちます。氷柱とハンマーの進行はスクロール速度に合わせ、一時停止中は停止し、コース切り替えでリセットします。

## メニューへ戻る

ゲームオーバー画面で **B** を押すとタイトルメニューへ戻ります。Aで再挑戦もできます。メニューからAまたはSTARTで再開するとクリア数・魚は0になり、選択モードの初期難易度・速度・BGMテンポに戻ります。同じ起動中のベスト記録はモード別に保持します。

## v10 の雪玉と浮遊ブロック

5ステージ目（4コースクリア後）から、しろくまがペンギンに向かって雪玉を投げます。近づくと雪玉を持ち上げ、12更新の予備動作後に左へ投げます。通常時は雪玉に触れると即ゲームオーバー。雪玉はジャンプで避けられ、しろくまは従来どおり上から踏んで倒せます。既に投げられた雪玉は、しろくまを倒しても飛び続けます。

各コースの中盤には16×16 pxの浮遊ブロックが1個あります。10ステージ目以降、その区間が氷柱に選ばれるとブロックは出ません。地上を走って下を通れますが、ジャンプ中に触れるとゲームオーバー。魚の列もブロックの下へ続きます。穴やしろくまの移動範囲とは重ならず、手前のジャンプから着地する余裕を残しています。

無敵中は雪玉に当たると雪玉が消え、浮遊ブロックにも耐えられます。一時停止中は雪玉と投げる予備動作も止まります。コースが変わると雪玉を片付け、再挑戦では各モードの初期難易度に戻り、NORMALでは雪玉は出ず、HARDでは最初から出ます。

## v9 のBGM連動

魚100匹ごとの無敵中だけ、きらびやかなオリジナル曲「Aurora Dash」へ切り替わります。無敵が切れると通常曲「Snowbound Hop」の冒頭へ戻ります。無敵を次のコースへ持ち越している間も専用曲が続きます。

コースクリアごとのスクロール速度と同じ比率で、両方のBGMのテンポが120 BPMから最大180 BPMまで上がります。1クリアにつき約2.14 BPM、29コース目から上限です。音程と効果音の速さは変わりません。再挑戦するとNORMALは120 BPM、HARDは約160.7 BPMへ戻ります。

## 基本のBGM

明るいオリジナル曲「Snowbound Hop」を追加。16小節・120 BPM・32秒のループです。タイトルとプレイ中に流れ、コースをまたいで継続します。STARTの一時停止とゲームオーバーでは止まり、再開では続きから再生し、再挑戦では通常曲の冒頭へ戻ります。メロディー、低音、打楽器の3チャンネルを使い、従来の効果音には専用チャンネルを残しています。

編集用の `assets/music/SnowboundHop.uge` と作曲元 `music-source/compose.ts` を同梱。詳しくは `music-source/README.md` を参照。

## v7 の表示修正

しろくまのタイルを 24 px キャンバスの中心に合わせ、原点も同じだけ補正しました。右端 4 px が変換時に欠けて別タイルと混ざる問題を解消し、画面上の位置と当たり判定は維持しています。左右の歩行と倒れた姿の全 5 コマについて、ROM から復元した絵と元 PNG が一致する検査を追加しました。

## 新しい遊び方

- A を押してジャンプし、空中で一度離してもう一度 A を押すと二段ジャンプ。着地するたびに 2 回へ戻ります。押しっぱなしでは二段目や次のジャンプは出ず、三段ジャンプもできません。
- コースごと・再挑戦ごとに氷 3 個・穴 4 個・しろくま 2 体・浮遊ブロック 1 個を配置。二段ジャンプ後に着地する余裕を作るため、障害物の間隔を 160〜192 px に広げました。10ステージ目からは序盤・中盤・終盤の1〜3区間が氷柱に替わり、15ステージ目からはしろくま1体が黒熊に替わり、20ステージ目からは最初のペアの高い氷が隕石区間に替わります。
- 氷の高さは 16 / 24 / 48 / 56 px。48 px の高い氷は最初のコースから、56 px は 3 コース目から登場。高い氷には二段ジャンプが必要です。
- 穴は幅 32 / 40 / 56 / 64 px。56 px の広い穴は最初から、64 px は 3 コース目から登場。落下が始まるとジャンプは使えず、穴の途中への着地も落下扱いです。
- しろくまは安全な地面を左右に往復します。横から触れるとミス。下降中に上から踏むと倒せます。踏んだ直後は自動で小さく跳ね、A を押し直せば空中であと 1 回ジャンプできます。無敵中は地上で触れても倒せます。
- しろくまの移動範囲は配置の中心から左右 16 px。穴へは入らず、2 体の間には十分な距離を確保しています。倒した個体はそのコース中は復活しません。
- ゴールするとクリア数が増え、短い結果表示のあと自動で次のコースへ進みます。クリアのたびに速度が 1/32 px/更新ずつ上がります。初速は 1.75 px/更新で、28 回クリア後（29 コース目）に初速の 1.5 倍へ到達し、その後は一定です。高速でも高い氷・広い穴を越えられるよう、ジャンプの動きも速度に合わせて調整しています。
- 各コースに魚を 60 匹配置。地上の列、一段ジャンプの列、二段ジャンプで取る高い列があります。魚の位置も氷・穴に合わせて変わります。
- 累計 100、200、300…匹ごとに約 8 秒間無敵になります。ペンギンが点滅し、`STAR` の横に残り時間のゲージと秒数を表示します。80 px のゲージが約 0.1 秒ごとに 1 px ずつ減り、次の 100 匹で満タンに戻ります。氷に触れてもミスにならず、穴の上も走れます。
- 魚・無敵の残り時間は次のコースへ持ち越します。一時停止中とコース結果の表示中は無敵時間が減りません。
- ミスするとクリア数と魚の合計を表示。ベストはクリア数を優先し、同じクリア数なら魚の多い記録を採用し、NORMALとHARDは別々に管理します。**ベストは同じ起動中だけ保持し、電源を切ると消えます。**

## 操作

| 操作 | Game Boy / Chromatic | ブラウザー |
|---|---|---|
| モード選択（タイトル） | 左: NORMAL / 右: HARD、SELECTで切替 | ← / →、Pで切替 |
| タイトルから開始 | A または START | Z または Enter |
| ジャンプ | A | Z |
| 高くジャンプ | A を長押し | Z を長押し |
| 二段ジャンプ | 空中で A を離して押し直す | 空中で Z を離して押し直す |
| 一時停止 | START | Enter |
| 一時停止から再開 | A または START | Z または Enter |
| ミス後に再挑戦 | A | Z |
| ミス後にメニューへ戻る | B | X |

右への移動は自動です。通常の氷には一段ジャンプ、高い氷には少し早めの一段目から、頂点付近でもう一度 A を押す二段ジャンプが有効です。広い穴も一段で無理に越えず、穴に差しかかったところで二段目を使います。各段で A を長押しすると高く跳べます。

着地後も押しっぱなしでは次のジャンプは出ません。次の障害物の前で一度離して押し直してください。再挑戦で今回のクリア数・魚・無敵時間・ジャンプ回数はリセットされ、スクロール速度も選択モードの初速へ戻ります。

画面下の `C` はクリア済みコース数、`J` は残りジャンプ回数（2→1→0、着地で2）。落下が始まると0になります。`FISH` ゲージは次の100匹までの進捗です。無敵中は `STAR` ゲージと残り秒数へ切り替わります。表示上限はクリア数 9,999、リザルトの魚 65,535。上限後も走行は続きます。

## ファイルと実機

- **`build/PenguinJump-v19.gbc`**: ステージ20以降の吹雪・氷柱3倍・隕石3倍入りの最新版。128 KiB の GBC 専用 ROM。
- `project.gbsproj`: GB Studio で開ける編集用プロジェクト。
- `assets/`: 背景、ペンギン・魚・氷・穴、フォント、UI。
- `plugins/penguin-runner/`: ランダム配置、ジャンプ、魚、無敵、コース進行、結果表示のシーン拡張。

## 編集・ビルド

GB Studio CLI 4.3.2 / GBDK 4.5.0 / エンジン `4.3.0-e1`。通常のネイティブプロジェクトに独自の `PENGUIN` シーンタイプを加えています。音楽マネージャーはプロジェクト内のプラグインで上書きし、共有ツールチェーンは変更していません。

```sh
gb-studio-cli make:rom project.gbsproj build/PenguinJump-v19.gbc
gb-studio-cli make:web project.gbsproj build/web
```

ModRetro Chromatic プラグインでは、この `project.gbsproj` を選択して `rom_build` / `web_preview` を使用できます。ブラウザー版は Codex の内蔵ブラウザーで開いてください。ローカル URL はプラグインの終了・再起動で失効する場合があります。

速度・重力・無敵時間・生成規則は `plugins/penguin-runner/engine/src/states/penguin.c` にあります。シーン内の最初の 2 アクターは氷・穴・浮遊ブロック、続く 8 アクターは魚、その次の 2 アクターはしろくま、続く 2 アクターは雪玉、続く 2 アクターは氷柱と予告マーカー、続く 2 アクターは黒熊とハンマー、最後の 2 アクターは隕石と専用の予告マーカーの表示用です。v19では予告マーカー用の2枠を増量した氷柱に使用し、雪玉用の2枠を隕石区間だけ増量弾に貸し出します。貸し出し後は雪玉の絵・タイル番号・フレーム範囲を戻します。この順序を維持してください。メニュー復帰用の `pj_menu_script.s` はタイトルのネイティブシーンシンボル `scene_start` を参照します。障害物の衝突は生成した座標を使い、背景の衝突タイルには依存しません。HUD のタイルは `create_art.py` から生成します。穴のタイルはスプライト編集用キャンバス内に置き、実行時の Y 座標で地面へ移動しています。穴は通常走行中のペンギンと別の走査線に描き、HUD の上にも描画しません。隣り合う穴が表示数の上限を超えないよう、画面外の部分を省いたネイティブフレームを使います。

永続セーブは未実装。ジャンプ、回収、無敵開始、衝突、クリアに短い効果音があります。実機での音・入力遅延は未確認です。

## 素材

ペンギン、魚、氷、穴、しろくま、雪玉、浮遊ブロック、氷柱、黒熊、ハンマー、隕石、タイトル、星空・山・氷原、HUD とBGMはこのゲーム用のオリジナル素材です。標準フォント・枠はプラグインの blank project 付属素材で、付属の `LICENSE` を保持しています。

黒熊7コマとハンマー4コマは `verify_enemy_rom.py build/PenguinJump-v18.gbc --sprite black_bear` / `--sprite hammer` でROM画素と元PNGを照合できます。ネイティブOBJパレットは今回のコンパイラーで `colors[0]`, `colors[1]`, `colors[3]` が不透明色に使われるため、黒熊の体色は `colors[1]` に指定しています。

オープニングの更新処理は `plugins/penguin-runner/engine/src/states/logo.c`、8コマの2bppデータは `include/states/penguin_title.h` にあります。`create_art.py` が静止PNGとアニメーションデータを同時生成します。背景バンク1のタイル128〜143を32×32 pxのアニメーション領域、144〜246をモード選択メニューに使います。`penguin_mode.h` の共有モード値をタイトルとゲームが参照し、`pj_level` を実クリア数から独立した難易度として生成時に計算します。タイトルの入力は更新を止めるAwait Inputではなく、A / STARTの入力イベントとして登録しています。

隕石の素材を再登録・変更するときは、登録済みIDと**固有シンボル `sprite_meteor`**を維持してください。ペンギンの `sprite_sprite` と重複すると、コンパイル時に同じ出力を上書きします。パレットはシーンのOBJスロット6です。`python3 art-source/verify_enemy_rom.py build/PenguinJump-v18.gbc --sprite meteor` で、コンパイル後の隕石2コマと元PNGを画素ごとに比較できます。
